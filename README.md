# LC-3 ASM Conversion Script

Converts LC-3 assembly to human-readable binary machine code

This script assumes that you have [lc3tools](https://lumetta.web.engr.illinois.edu/ase2021.html) installed

## Usage

```sh
curl -sL https://raw.githubusercontent.com/benson-z/lc3_asm_convert/refs/heads/main/lc3_asm_convert.sh | sh -s -- <file>
```
